# AI Resume Analyzer

An AI-powered FastAPI application that analyzes resumes and compares them with job descriptions to provide skill gap insights.

## Features
- Extracts text from resume PDFs
- Generates AI-based resume feedback
- Compares resume with job description
- Returns structured skill gap analysis
- Built using FastAPI and Hugging Face LLM

## Tech Stack
- Python
- FastAPI
- Hugging Face Inference API
- LLM (Meta Llama 3)
